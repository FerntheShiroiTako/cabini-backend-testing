CABSITE Backend

Setup, deployment and operations. Fanart gallery with Discord login and a moderator queue, running as a single Cloudflare Worker.

1. What was built

The existing static site and a new backend now ship as one Cloudflare Worker. There is no second server, no separate origin, and no CORS. The DigitalOcean droplet is not involved.

LayerTechnologyRole
Static pagesWorkers AssetsServes everything in public/
BackendTypeScript + Hono/auth/*, /api/*, /art/*
SessionsKVSession id → user id, 7 day TTL
Relational dataD1Users, posts, roles
Image filesR2Uploaded art, free egress
LoginDiscord OAuthNo passwords stored
Bot protectionTurnstileOn the upload route

The rule that drives the design

Nothing becomes public without a moderator approving it. Uploads land as pending. Pending images return 404 to everyone except moderators and the owner. Rejection deletes the database row and the R2 object — there is no third status and no archive.

2. Where everything lives

cabini/ ├─ public/ ← served to browsers, this is the web root │ ├─ index.html the original shrine, unchanged │ ├─ style.css script.js favicon.ico media/ │ ├─ robots.txt sitemap.xml │ ├─ gallery.html + gallery.js approved art │ ├─ upload.html + upload.js submission form │ ├─ admin.html + admin.js moderator queue │ ├─ owner.html + owner.js staff management (owner only) │ └─ nav-auth.js shared nav + sign in state ├─ src/ ← the Worker, never served to browsers │ ├─ index.ts routing, /api/me, /art/* image serving │ ├─ auth.ts Discord OAuth │ ├─ session.ts cookie → KV → D1, role guards │ ├─ cookie.ts HMAC signing │ ├─ posts.ts gallery list + upload │ ├─ admin.ts moderator queue │ ├─ owner.ts promote / demote moderators │ ├─ turnstile.ts image.ts types.ts ├─ schema.sql database tables ├─ wrangler.jsonc config + public vars ├─ .dev.vars local secrets, gitignored └─ .wrangler/ local database + files, gitignored

Anything you put in public/ is publicly downloadable. That is the whole point of the folder, but it means secrets, notes and backups must never go there. Worker code in src/ is compiled and never exposed.

3. Permission tiers

TierHow it is grantedCan do
AnyoneNo accountView the shrine and approved art
MemberAutomatic on first Discord loginSubmit art for review
ModeratorGranted by the owner on the Staff pageApprove or reject submissions, preview pending art
OwnerDiscord ID in wrangler.jsoncEverything a moderator can, plus add and remove moderators

The owner is you, pinned to Discord ID 733654151107444797. This is deliberately not stored as a database role:

  • It cannot be taken. Anyone who gained write access to the database still could not make themselves owner — the check reads config, not a table.
  • It cannot lock you out. On an empty database there are no moderators yet. Because owner comes from config, you can sign in and appoint the first one immediately.
  • It survives a database wipe. Restore from nothing and you are still owner.

The consequence: your row in the users table says member, and that is correct. Owner status is layered on top at request time.

4. Setup you still have to do

Everything below is required before the site works in production. Local development already works with none of it.

Step 1  Create the Discord application

  1. Go to discord.com/developers/applications and click New Application.
  2. Open OAuth2. Copy the Client ID and reset/copy the Client Secret.
  3. Under Redirects, add both of these, exactly:
http://localhost:8787/auth/callback
https://cabinithepanini.com/auth/callback

These must match character for character — including http vs https and no trailing slash. A mismatch gives an invalid_redirect_uri error at login and is the single most common thing to get wrong here.

Step 2  Create a Turnstile widget

  1. Cloudflare dashboard → Turnstile → Add site.
  2. Hostname cabinithepanini.com. Add localhost too if you want the real widget locally.
  3. Copy the Site Key (public) and Secret Key (private).

Step 3  Create the Cloudflare resources

npx wrangler d1 create cabsite
npx wrangler kv namespace create SESSIONS
npx wrangler r2 bucket create cabsite-art

Each command prints an ID. Paste them into wrangler.jsonc, replacing the "local" placeholders.

R2 is the one product that asks for billing details up front. You will not be charged — 10 GB of storage is free and egress is always free — but the card has to be on file before the bucket can be created. Everything else is on the free plan. This is why local development was built to need none of it.

Step 4  Fill in the public config

In wrangler.jsonc, under vars. These are not secrets and are safe to commit:

"vars": {
  "DISCORD_CLIENT_ID":    "your client id from step 1",
  "DISCORD_REDIRECT_URI": "https://cabinithepanini.com/auth/callback",
  "TURNSTILE_SITE_KEY":   "your site key from step 2",
  "OWNER_DISCORD_ID":     "733654151107444797"
}

Two values ship as local-development defaults and will break production if left alone.

DISCORD_REDIRECT_URI is currently http://localhost:8787/auth/callback. Deploy that and every login fails.

TURNSTILE_SITE_KEY is currently 1x00000000000000000000AA, Cloudflare's test key that always passes. Deploy that and the bot check is decorative.

Step 5  Set the secrets

These are encrypted by Cloudflare and never appear in the repository:

npx wrangler secret put DISCORD_CLIENT_SECRET
npx wrangler secret put TURNSTILE_SECRET
npx wrangler secret put COOKIE_SECRET

For COOKIE_SECRET, paste a long random string. Generate one with:

node -e "console.log(crypto.randomUUID() + crypto.randomUUID())"

This key signs session cookies. Changing it later signs everyone out — which is also how you force a global logout if a session is ever compromised.

Step 6  Create the tables and deploy

npx wrangler d1 execute cabsite --remote --file=./schema.sql
npx wrangler deploy

schema.sql begins with DROP TABLE IF EXISTS. Running it against a live database erases every user and post. Run it once at setup. After that, write migrations instead.

Step 7  Appoint your moderators

  1. Visit https://cabinithepanini.com/gallery and sign in with Discord.
  2. A Staff link appears in the nav. It is visible only to you.
  3. Have your moderators sign in once so they have an account.
  4. On the Staff page, click Make moderator next to each.

Role changes apply on their next request. Nobody needs to sign out and back in.

File type is decided by reading the first bytes of the file, not by trusting what the browser claims. Renaming virus.exe to art.png does not get past it. To change the size cap, edit MAX_BYTES in src/image.ts.

7. Day to day operations

Local development

npm install
npm run db:init     # create tables in the local database
npm run dev         # http://localhost:8787

Local mode simulates D1, KV and R2 on disk under .wrangler/state. Nothing touches your Cloudflare account and nothing is billed. To wipe local data and start clean:

rm -rf .wrangler/state
npm run db:init

Promote someone without the web page

npx wrangler d1 execute cabsite --remote \
  --command "UPDATE users SET role='moderator' WHERE username='NAME';"

Look at the live data

npx wrangler d1 execute cabsite --remote --command "SELECT username, role FROM users;"
npx wrangler d1 execute cabsite --remote --command "SELECT COUNT(*) FROM posts WHERE status='pending';"
npx wrangler tail                 # live request logs

Back up the database

npx wrangler d1 export cabsite --remote --output=backup.sql

D1 keeps 30 days of point-in-time recovery on paid plans. Manual exports are worth taking before any schema change.

9. When something breaks

SymptomCause and fix
invalid_redirect_uri at loginThe Discord redirect list does not exactly match DISCORD_REDIRECT_URI. Compare both, character for character.
Signed in, but treated as signed outCOOKIE_SECRET changed, or the 7 day session expired. Sign in again.
No Staff link in the navOWNER_DISCORD_ID does not match the account you logged in with. Check /api/me and compare discord_id.
Every upload fails the bot checkTURNSTILE_SECRET and TURNSTILE_SITE_KEY are from different widgets, or the site key is still the test value.
Gallery loads but images are blankThose posts are still pending, or the R2 bucket ID in wrangler.jsonc is wrong.
Anything unexplainednpx wrangler tail streams live errors from production.

10. Costs

Free to run at your scale. Workers allows 100,000 requests a day on the free plan; the paid plan is $5 a month if you outgrow it. R2 gives 10 GB free, then $0.015 per GB per month, and egress is always free — which is what matters for an image gallery. D1, KV and Turnstile are all covered by the free plan.

At 5 MB per image, 10 GB holds roughly 2,000 submissions before storage costs anything at all.
